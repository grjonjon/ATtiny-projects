This is a ATtiny13A project to automate a small cheap china-made bedside battery lamp (actually a desktop reading lamp) that originally uses 3xAAA batteries and only had a pushon-pushoff switch. The circuit presented, along with the code, adds a timer to turn the lamp off after 15 minutes; this should give the user (my mother) enough time to check the time at night and even fall asleep without worrying that she'll find the lamp on in the morning and the batteries almost dead. The circuit uses an ATtinny13A, a few resistors and a BS170 (or equiv.) N-channel MOSFET. To re-enable the circuit once it switches off by itself, the user need to press on the switch twice (OFF and back ON) in which case the circuit will reset and start the timer over.
